NOTES
-----
* switchTab is generic — it already activates #nfl-panel by convention.
  The wrapper only adds first-open lazy loading; it does not replace the router.
* The loader expects GET /api/nfl/slate?date=YYYY-MM-DD returning
  { source, picks: [{ player, player_key, propLabel, verdict, outlook? }] }
  where verdict is the nflClassify.classifyProp() output shape.
* Off-season / missing endpoint => honest empty state, never a fabricated pick.
* Qualifying picks (tier != none) auto-register into the existing parlay
  builder via setSportCandidates('nfl', ...) — same seam MLB/WNBA use.
